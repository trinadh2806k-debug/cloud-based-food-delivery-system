│

## Description
A college-level cloud computing web application that simulates a cloud-based food delivery platform.

## Features
- Cloud kitchen food ordering
- INR pricing and shopping cart
- Email sign-in and registration UI
- Live delivery/drone tracking simulation
- Kitchen order queue
- Cloud infrastructure telemetry dashboard
- Traffic spike and regional failover simulation
- Cloud architecture visualization
- Responsive glassmorphism interface
- Simulated real-time cloud metrics

## Technologies
HTML5, CSS3, JavaScript, Font Awesome, Google Fonts, LocalStorage.

## Cloud Concepts
API Gateway, serverless computing, AWS Lambda concept, Kafka event streaming, DynamoDB global database concept, multi-region architecture, failover, telemetry, IoT/drone tracking, and microservices.

## How to Run
1. Open this folder in VS Code.
2. Keep all four files in the same folder.
3. Open `index.html` directly or use the VS Code Live Server extension.
4. Explore the Cloud Kitchens, Live Tracking, Kitchen Terminal, Ops Dashboard, and Architecture tabs.

## Important Note
This is a front-end college demo. AWS Lambda, Kafka, DynamoDB, and the drone network are simulated in JavaScript; no real cloud resources are deployed.
